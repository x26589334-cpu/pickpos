# 상권별 「구입 vs 렌탈」 비교글 — 양식과 규칙

> 사용자가 **"오늘 글 써줘"** 라고 하면 이 파일과 `지역목록.md` 를 읽고 아래 절차대로 글 1편을 만들어 발행한다.
> 이 폴더(`_content/`)는 `_` 로 시작해서 GitHub Pages(Jekyll)가 **게시하지 않는다**. 작업용 파일만 둔다.

## 전략 (2026-09-05 변경 — 이전 방침을 대체한다)
- **H포스와 키워드가 겹쳐도 된다.** hpos.co.kr 과 hsupporter.com 은 **서로 다른 도메인**이라 검색 결과에 각각 올라간다. 같은 검색어에서 1등과 3등을 동시에 먹는 게 목표다. (키워드 전문가 조언 · 사용자 결정)
- 지역명·행정구역·"설치" 같은 단어를 **피하지 않는다.** 동네 + 제품 키워드를 최대한 넣는다.
- **단 하나의 금지선: 본문이 H포스와 비슷하면 안 된다.** 내용이 겹치면 구글이 한쪽을 걸러낸다. 키워드는 같이 쓰되 **각도를 다르게** 쓴다.
  - H포스 = 「설치 안내」 (동 단위 방문, 설치비 0원, 평균 4일, 카드가맹 안내)
  - 픽포스 = 「비용·비교」 (구입 vs 렌탈, 36개월 총액, 손익분기, 동네별 추천 구성)
  - 새 글을 쓰기 전 `yoon` 리포의 해당 지역 페이지를 열어 **소제목이 겹치지 않는지** 확인할 것

## 콘텐츠 두 종류
**A. 비교 가이드 `compare/`** — 상권 단위, 블로그 느낌. 「{상권} 포스기 구입 vs 렌탈, 36개월 총비용 비교」
**B. 지역별 견적 `region/`** — 행정구역 단위, 키워드 집약. 「{지역} 포스기·카드단말기 견적 — 동네별 추천 구성과 비용」
원본 템플릿은 각각 `compare/gangnam-station.html`, `region/gangnam.html`.
B 는 동·역 이름을 대량으로 넣되 **동네마다 실제 상권 설명 1~2문장**을 붙여 얇은 페이지가 되지 않게 한다.
A 와 B 는 서로 링크한다 (A 하단 "다른 동네" 문단 → B, B 의 해당 상권 카드 → A).

## 파일·URL
- 글: `compare/{slug}.html` — slug 는 `지역목록.md` 에 정해져 있음 (영문 소문자·하이픈)
- OG 이미지: `compare/og/{slug}.png` (1200×630) — 글마다 1장, 아래 8단계에서 생성
- 목록: `compare/index.html` 카드 1개 추가
- 사이트맵: `sitemap.xml` `<url>` 1개 추가 (lastmod = 오늘, changefreq monthly, priority 0.7)

## 글 구조 (강남역 글 `compare/gangnam-station.html` 이 원본 — 복사해서 시작)
1. **제목(h1)**: `{상권} 포스기 구입 vs 렌탈, 36개월 총비용 비교`
2. **리드 2문단**: 그 상권 사람들이 실제로 묻는 질문 → "구성에 따라 답이 뒤집힌다" 한 줄 → 이 상권 기준으로 계산했다
3. **결론부터(표)**: 4개 구성(포스기 단독 / 포스기+단말기 / 카페 세트 / 식당 세트)의 36개월 렌탈·구입·유리한 쪽
4. **장비별 소제목 4~5개**: 포스기 단독 → 카드단말기 함께 → 카페(키오스크) → 식당(테이블오더) → 무인매장(자판기). **각 소제목마다 그 상권 얘기 1~2문장 반드시** (임대료·회전율·업종 분포·유동인구 성격 등 `지역목록.md` 메모 활용)
5. **정리(2칸)**: "렌탈이 맞는 경우" / "구입이 맞는 경우" 각 4개
6. **FAQ 4개**: 첫 질문은 반드시 `{상권} 근처인데 방문 견적도 되나요?` (답에 인접 동네 2~3개 자연스럽게)
7. **CTA**: 전화 010-6832-1994 + `../#quote` 버튼
8. **주석**: 렌탈료 기본요금 기준 / 구입가 참고용 예시 문구 (푸터 문구와 일치)
9. **관련 링크**: `../#calc`(계산기) · `../#quote`(견적) · `./`(목록)

분량: 본문 1,300~1,800자(공백 제외). 표·FAQ 포함하면 화면 기준 A4 2장 안팎.

## 키워드 규칙
- **지역**: 상권·역·동 이름 (강남역, 역삼동, 테헤란로, 신논현역…). 인접 상권 3~5개를 본문 곳곳에 **그 지역 얘기를 하면서** 넣는다. `{시군구} 포스기 설치` 형식은 **금지**(H포스 영역).
- **제품**: 포스기 · 카드단말기 · 무선/블루투스 카드단말기 · 토스페이결제기 · 키오스크 · 테이블오더 · 무인자판기 · 주방프린터. 자연스럽게 나오는 자리에서만.
- **의도어**: 구입 · 렌탈 · 견적 · 비용 · 총비용 · 손익분기 · 36개월 · 가격 · 얼마 · 설치 · 방문 · 교체. 제한 없음.
- 지역명만 바꾼 복사본이 되면 실패다. **지역 문장이 실제로 다른가**를 발행 전 확인. 이건 H포스 때문이 아니라 구글의 도어웨이 판정 때문에 여전히 유효하다.

## 금액 계산 (반드시 `script.js` 의 `PRICE` 에서 읽어서 계산 — 외워 쓰지 말 것)
- 36개월 렌탈 총액 = 월렌탈료 × 36
- 손익분기(개월) = 구입가 ÷ 월렌탈료 → **올림**해서 "N개월차부터 구입 유리"
- 차액 = |렌탈 총액 − 구입가|, 유리한 쪽 표시
- 세트 구성은 `index.html` #sets 의 구성 그대로: 카페 = 키오스크1+포스1+단말기1 / 식당 = 테이블오더8+포스1+단말기1(+주방프린터, 가격 미포함)
- 요금이 바뀌면 이미 발행한 글의 숫자도 바뀌어야 한다 → `PRICE` 수정 시 `compare/` 글 전체 grep 해서 갱신 (나중에 생성기로 자동화 예정)

## 문체
- 사장님에게 말하듯, 존댓말, 단정하게. "~입니다 / ~합니다".
- 숫자는 천 단위 콤마 + 원. 유리한 쪽은 **굵게**.
- 한 문단 3문장 이내. 소제목 뒤엔 결론을 먼저.
- 과장 금지: "업계 최저", "무조건" 같은 말 X (무인자판기처럼 수치가 압도적일 때만 "구입 외 선택지가 없다" 허용)

## 발행 절차 ("오늘 글 써줘" 받았을 때)
> 사용자가 종류를 안 말하면 **A(비교 가이드)와 B(지역별 견적)를 번갈아** 쓴다.
> B 를 쓸 때는 3~8단계 대신 `region/gangnam.html` 을 복사해 동네 카드·역 목록·가격표·업종별을 그 지역 것으로 새로 쓰고,
> `region/index.html` 의 "준비 중" 을 링크로 바꾸고, OG 는 공용 `og-image.png` 를 쓴다(전용 그래픽 불필요).
1. `git status` 깨끗한지 → `git pull --ff-only`
2. `지역목록.md` 에서 상태가 비어 있는 **가장 위** 지역을 고른다 (사용자가 지정하면 그 지역)
3. `compare/gangnam-station.html` 을 복사해 `compare/{slug}.html` 생성 → 제목·메타·canonical·og·JSON-LD(headline, url, datePublished, image, FAQ)·본문 전부 교체
4. 본문의 지역 문장을 `지역목록.md` 메모 기준으로 새로 쓴다 (복붙 금지)
5. 숫자는 `PRICE` 로 다시 계산해 넣는다
6. `compare/index.html` 카드 추가 (최신 글이 맨 앞)
7. `sitemap.xml` 에 url 추가
8. OG 이미지: `_content/og-template.html` 의 `{{EYEBROW}} {{TITLE}} {{SUB}} {{RENT}} {{BUY}} {{RENT_W}} {{BUY_W}} {{VERDICT}}` 를 채워 임시 파일로 저장 후
   ```
   "C:\Program Files\Google\Chrome\Application\chrome.exe" --headless=new --disable-gpu --hide-scrollbars ^
     --window-size=1200,630 --virtual-time-budget=12000 ^
     --screenshot="C:\Users\COMMUNITY KOREA\pickpos\compare\og\{slug}.png" "file:///C:/{임시파일 절대경로}"
   ```
   (`--screenshot` 은 **절대경로** 아니면 "액세스 거부"로 실패한다. 상대경로 X)
9. 헤드리스 크롬으로 글 페이지 스크린샷 1장 찍어 깨진 곳 없는지 확인
10. `지역목록.md` 상태 칸에 `✅ YYYY-MM-DD`
11. `git add -A` → 커밋 `비교글 추가: {상권} 구입 vs 렌탈` → `git push`
12. `사이트관리/작업로그.md` 맨 위에 완료 한 줄
